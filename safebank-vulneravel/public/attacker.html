📚 Contexto Educacional

Esta página representa o que um atacante hospedaria em outro domínio.

Como o ataque funciona:

  1. Vítima está logada no SafeBank (tem o cookie session_id)
  2. Vítima clica num link malicioso (e-mail, anúncio, etc.)
  3. A página do atacante envia formulário automaticamente para o banco
  4. O navegador inclui o cookie de sessão na requisição
  5. O servidor processa a transferência como legítima

Proteção: Token CSRF único por sessão + SameSite=Strict no cookie
